# ADR-0004: M1 scope control

## Status

Accepted.

## Context

The Lastenheft and Pflichtenheft intentionally cover a larger product vision. Treating all of it as M1 would block progress.

## Decision

M1 is split into M1a Core and M1b Modern FIRST-ED demo. Advanced features are postponed to M2+.

## Consequences

- The project can produce a usable core quickly.
- Advanced features remain visible in the roadmap.
- Contributors must not treat all 208 requirements as the first implementation task.
