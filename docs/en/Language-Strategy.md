# Language Strategy

C#/.NET is the first and reference implementation. Other languages are prepared through concise, practical specifications and conformance tests, but they are not developed in parallel during M1.

Stable across languages:

- editor concepts;
- command IDs;
- settings and keyboard profile formats;
- observable behavior;
- conformance vectors.

Idiomatic per language:

- error handling;
- async/threading;
- strings and memory management;
- UI adapters;
- package conventions.

Java and C++ are possible future full implementations. PHP is currently planned only as a possible integration/server-side package, not as the first rich editor core.
