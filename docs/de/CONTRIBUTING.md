# Mitwirken

Dieses Projekt befindet sich noch in einer frühen Entwicklungsphase. Beiträge sollten zunächst den M1-Pfad stärken: Korrektheit des Core, Tests, sicheres Speichern und die erste WinForms-Demo.

Bitte zuvor lesen:

- `AGENTS.md`
- `docs/de/ROADMAP.md`
- `docs/de/Mehrsprachenstrategie.md`
- `docs/adr/`

Pull Requests möglichst klein halten und, wo sinnvoll, mit einem Roadmap-Abschnitt oder einer Anforderungs-ID verknüpfen.

## Codex / KI-Agenten

KI-Agenten müssen zuerst `AGENTS.md` lesen. Für autonome Arbeit sind außerdem `docs/ai/CODEX-AUTONOMY.md`, `docs/ai/CURRENT-STATE.md` und `docs/ai/NEXT-WORK.md` maßgeblich. Die spezifischen `AGENTS.md`-Anweisungen für Core, WinForms, Sample und Tests gelten zusätzlich.

In diesem derzeit von einer Person entwickelten Repository ist direkte Arbeit auf `main` gemäß `AGENTS.md` erlaubt. Ältere, branchbezogene Notizen begründen keine allgemeine Pull-Request-Pflicht.
