# Contributing

This project is currently in repository-seed phase. Contributions should first strengthen the M1 path: Core correctness, tests, storage safety and the first WinForms demo.

Please read:

- `AGENTS.md`
- `ROADMAP.md`
- `docs/de/Mehrsprachenstrategie.md`
- `docs/adr/`

Keep pull requests small and connect them to a roadmap section or requirement ID when possible.


## Codex / AI agents

AI coding agents must read `AGENTS.md` first. For autonomous work, also read `docs/ai/CODEX-AUTONOMY.md`, `docs/ai/CURRENT-STATE.md` and `docs/ai/NEXT-WORK.md`. Subtree-specific `AGENTS.md` files apply to Core, WinForms, the sample and tests.

This single-developer repository currently permits direct work on `main` as described in `AGENTS.md`; do not infer a pull-request requirement from older branch-specific notes.
